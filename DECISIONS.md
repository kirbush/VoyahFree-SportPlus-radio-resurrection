# Решения

- Два приложения в одном Windows-установщике: обычное радио со штатным UI и отдельная диагностика.
- Один backend управляет аппаратным FM-блоком. Диагностика использует защищённый API и не запускает второй адаптер.
- FM-комплект устанавливается в `/data`; системные разделы и автозапуск Tweaks не изменяются. Установленный Tweaks — допустимое условие работы.
- Штатные Adayo/RDS APK сохраняются без изменений и переподписи; в публичном Git хранятся наши исходники, а не эти APK.
- Логи включены автоматически, отчёт сохраняется отдельной кнопкой и выгружается на ПК через файл с выбором папки.
- Обновление сохраняет настройки станций, отчёты и существующий FM-процесс; очистка касается только устаревших служебных файлов нашего комплекта.
- Автоматическое воспроизведение после пробуждения не является обязательным условием: оно зависит от настроек Tweaks и штатного поведения.
- Android-скрипты — LF без BOM. Проверяем сырые байты исходников и подписанного APK до выпуска.
- Совместимость с будущими обновлениями прошивки проверяется отдельно; сохранение `/data` не гарантирует неизменность интерфейсов и root-канала.
