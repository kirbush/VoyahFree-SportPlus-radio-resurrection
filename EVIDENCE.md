# Проверенные сведения

## Приёмник и PC-отправка, 22.10.2026

Пользователь выбрал свой рабочий VPS и предоставил SSH-доступ. Пароль был отклонён, затем вход выполнен предоставленным ключом. На сервере уже были nginx/HTTPS и таймер продления IP-сертификата. Публичный TCP 443 используется маршрутизацией TLS с другим назначением по умолчанию; проверенный HTTPS URL приёмника использует существующий 8443. Адреса, доступы и сырые серверные снимки хранятся локально вне Git.

Установлена отдельная включённая systemd-служба: loopback, непривилегированный пользователь, пустой набор capabilities, запрет изменения системных файлов, ограничения памяти/CPU/задач. Nginx проверяет ключ до тела ZIP; PUT-only API не предоставляет списка, чтения, удаления или команд. Архивы сохраняются вне web-root без извлечения, с ограничением фактического содержимого/метаданных, квотой и периодической уборкой.

Независимое ревью воспроизвело и проверило исправления: переполнение объектов центрального каталога, ZIP64 обход предварительных ограничений, поддельный нулевой размер 70 MiB deflate-потока, valid deflate boundary 65537, остановка повторов полной PC-очереди, уборка без новых загрузок. Последнее ревью: важных замечаний не осталось; реальные Java ZipOutputStream/data-descriptor ZIP и 72 допустимых сочетания размера/сжатия принимаются. В репозитории — 16 receiver-тестов и настоящий PowerShell с проверкой очереди/ограниченного чтения ответа; они включены в общий набор.

На реальном сервере синтетический ZIP принят по HTTPS, повтор после restart возвращает прежний id. Проверены настоящий Windows HttpWebRequest, локальное сохранение/очередь при остановке только нового приёмника и отправка после восстановления. Запросы без ключа/с неверным ключом — 401; чтение отчёта — 405, список/внутренний auth — 404, неверный хеш — 422, размер свыше лимита без тела — 413. Сохранённый файл совпадает побайтно, его владелец не root, права 0600; backend слушает только 127.0.0.1. Прежние nginx/AdGuardHome/home-cascade/coturn сохранили состояние.

Готовый Collect-2 отдельно распакован и выполнен с fake ADB и настоящим сервером: COLLECT_OK/UPLOAD_SENT, локальный ZIP сохранён, управляющих команд FM/установки нет. Живого подключения к автомобилю не было. APK беты 0.4.3 не менялись; автоотправка с самого ГУ пока не добавлена, проблема неполного автожурнала остаётся.

## Аппаратный тракт

Управление FM-блоком: STM32 CDC ACM `0483:5740`, `/dev/ttyACM0`, 115200 8N1.
