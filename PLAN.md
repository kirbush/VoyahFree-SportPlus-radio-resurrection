# План

Цель: поддерживать восстановление аппаратного FM-радио на Voyah Free Sport Plus после перехода на китайскую прошивку.

Текущий этап: разбор двух отчётов беты 0.4.3 до/после стоянки на прошивке 7.2.0. Перенос исходников в Git выполнен коммитом 96dccc1.

1. Подключить текущую рабочую папку к `kirbush/VoyahFree-SportPlus-radio-resurrection` и сохранить исходную историю README.
2. Импортировать FM-исходники и документы; исключить ключи, записи с машины, образы и локальные зависимости. Закрепить LF для Android-скриптов.
3. Повторить локальные проверки и проверку готового пакета; сверить состав Git перед публикацией.
4. Опубликовать исходники в репозитории и подтвердить совпадение локального и удалённого дерева.
5. Запуск 0.4.3 подтверждён. Найдены четыре падения штатного UI и пустой автожурнал; первоочередной следующий шаг — полноценный текст исключения, затем точечное исправление. Текущий запрос ограничен анализом; код не менялся.
6. После уточнения действий тестера отдельно исследовать аудиопропуски, сохранение последней частоты и полный цикл поиска. Одинаковый boot ID в новых отчётах исключает полную перезагрузку между ними; глубина сна неизвестна.

Уточнение: тестер не заметил проблем, избранное сохранилось. Яндекс Музыка автоматически запускается настройкой Tweaks, поэтому FM на паузе ожидаемо. Приоритет — полнота диагностики и текст исключений RdsApp; изменения звука, частоты и автозапуска без дополнительных оснований не планируются.

Второй тестер ещё проходит текущую версию. Пауза не помогла открыть диагностику, третий ролик показывает повторное появление её строки в диспетчере. Отчёта пока нет. Подготовлен отдельный PC-сборщик: новый ZIP без открытия приложения на ГУ, с дополнительными сведениями об окнах/Activity и исключениях. Получить его отчёт, затем сравнить результаты двух автомобилей и готовить следующую версию с упрощённым планом проверки, как просил пользователь. Сама бета остаётся 0.4.3; APK и FM-службы не менялись.
