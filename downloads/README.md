# Сборщик отчёта FM для Windows

[Скачать Voyah-FM-PC-Collect-1.zip](https://github.com/kirbush/VoyahFree-SportPlus-radio-resurrection/raw/refs/heads/main/downloads/Voyah-FM-PC-Collect-1.zip)

1. Распаковать архив целиком.
2. Подключить ПК к мультимедиа по USB.
3. Запустить **Collect-FM-now.cmd** и выбрать папку на ПК.
4. Дождаться **COLLECT_OK** и отправить созданный ZIP для разбора.

Открывать диагностику на ГУ не требуется. Это отдельный сборщик отчёта, приложения он не переустанавливает. ADB включён в архив.
