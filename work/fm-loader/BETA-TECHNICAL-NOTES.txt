FM 0.5.1 BETA — УСТРОЙСТВО КОМПЛЕКТА

Один наш APK: FM Радио, ru.local.voyah.fmloader, versionCode 9, прежний ключ.
Install-FM.ps1 устанавливает его через install -r и сохраняет UID, настройки,
отчёты и данные. После успешного обновления APK/помощника удаляется только
ru.local.voyah.fmdiagnostics; отсутствие старого пакета допустимо.
Неудачное удаление явно завершает установку с LEGACY_DIAGNOSTICS_REMOVE_FAILED.
Исходники прежней диагностики сохранены в репозитории для истории, но APK
диагностики в новом публичном установщике отсутствует.

На штатный экран RdsApp добавляется шестерёнка и native Android диалог.
Исходные AdayoDAB.apk/RdsApp.apk сохраняются побайтно и не переподписываются.
UI-bridge собирается в assets/radio-ui.dex и основной DEX нашего приложения;
в RDS он загружается отдельным selective injector из assets/ui.js.
Аппаратный adapter.js остаётся отдельным. Меню не открывает новую Activity.
Broadcast MenuActionReceiver ограничен android.permission.DUMP; API статуса
не возвращает приватный ключ. Работой радио/звуком владеет прежний один backend.

При установке останавливается только наш пакет и проверенный по /proc/cmdline
собственный broker. Adayo/RDS, их сервисы и PCM reader не останавливаются.
Миграция ждёт operation.lock через совместимый FD0, сохраняет lock-файлы,
настройки/журналы и маркеры текущего Adayo PID, удаляет лишь устаревший mailbox.
Android-скрипты проверяются как сырые байты: LF без BOM и правильный shebang.
Проверки действуют для исходников, подписанного APK, ZIP и установщика.
Версия runtime cache — 0.5.1-beta-v1.

Root-канал: adb root либо существующий su 0 при установке; после загрузки —
существующий канал VoyahTweaks через собственные LocalBootstrap/broker/helper.
Файлы Tweaks, system/vendor/boot/MCU и SELinux не изменяются. Нужны Android11/API30,
существующий Permissive, совместимый Tweaks и аппаратный FM-блок.
Данные помощника находятся в /data/local/tmp/voyah-fm-loader-v1.

Опциональный -UploadConfig по умолчанию ищет upload.json рядом с установщиком.
Проверяются HTTPS endpoint /voyah-fm/v1 без userinfo/query/fragment, client и token.
Проверка приватного JSON выполняется до Start-Transcript: Windows PowerShell
записывает текст исключения JSON-парсера в transcript даже при перехвате ошибки.
Сам ключ не включается в команды или журнал. Временная remote-папка имеет 0700;
итоговый /data/user/0/ru.local.voyah.fmloader/files/upload.json принадлежит UID
приложения и имеет 0600. Замена атомарная. Без файла существующий config сохранён.
Установщик не отправляет отчёты; приватный config отсутствует в публичном ZIP.

ReportCoordinator использует отдельный исполнитель. Send/save создают отчёт
асинхронно; capture/сеть не запускают tune/scan/play и не останавливают журналы.
Send использует HTTPS upload-only API, SHA256 idempotency и ограниченную очередь;
ошибка сети сохраняет ZIP. Периодический сбор начинается через 30 минут,
автоматическую отправку можно отключить. Save сохраняет ZIP в Downloads без
системного file-picker. Внутренние ZIP: files/Voyah-FM-report-*.zip.
PC-Export копирует готовые ZIP; Collect-FM-now создаёт новый PC ZIP через ADB
без управления радио, а Upload-FM-report.ps1 обеспечивает PC-отправку/очередь.
Публичный комплект содержит Collect-2 и upload.example.json, но не личный ключ.

Стек второго тестера показывает повторную регистрацию DisplayUtils$1 observer
в штатном RdsApp. UI guard ограничен повторной регистрацией этого observer.
Полное сохранение частоты, окончание поиска и причина загрузки ГУ после стоянки
требуют живой проверки. Автовоспроизведение после пробуждения не вводится:
критерий — работа радио после ручного открытия, с учётом настроек Tweaks.

Известный живой тест 0.4.3 относится к EB/build18. Совместимость образа7.3.1
подтверждена статически; это не подтверждение живого испытания7.3.1.
Локальные fake-ADB/сборочные проверки также не заменяют испытание на автомобиле.
Актуальные реальные результаты и ограничения находятся в EVIDENCE.md.

0.5.1: сохранение ZIP использует окончательное имя Downloads без IS_PENDING.
На собственном ГУ переход pending->published перемещает файл, но отклоняет
обновление БД (update=0, VolumeArgumentException: Downloads вне scan roots).
После копирования файл перечитывается по content URI, сравниваются длина и SHA256
с исходным приватным ZIP. При ошибке публичная копия удаляется, исходник сохранён.
Отправка, аудиотракт и автозапуск не менялись. Сон и кнопки руля на китайской
прошивке не объявляются исправленными.
